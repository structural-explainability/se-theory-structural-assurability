# Dominance and Incomparability

Structural Assurability compares systems through their claim-relative
evidentiary capability profiles.

The formal order supports several outcomes.

**Equivalence** means the systems expose the same capability profile for the
specified context.

**Dominance** means one system preserves the capabilities available from
another.

**Strict dominance** additionally requires at least one capability not
available from the weaker system.

**Incomparability** occurs when each system enables at least one relevant
capability unavailable from the other.

These relations do not establish a universal ranking because changing the
claim or evaluator context can change the comparison.
